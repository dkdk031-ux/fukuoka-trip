# 구글 시트에서 앱 배포하기 (Apps Script 웹 앱)

앱 전체를 구글 시트의 Apps Script로 배포합니다. **☆후쿠오카 폴더를 공유받은 사람만** 로그인해서 볼 수 있어요.

## 1. 코드 붙여넣기
1. 구글 시트(후쿠오카 여행 마스터 2026) → **확장 프로그램 → Apps Script**
2. `Code.gs` 내용을 모두 지우고, 이 폴더의 **`Code.gs`** 전체를 붙여넣기
3. 왼쪽 **파일 옆 ＋ → HTML** → 이름을 `index` 로 만들고, 이 폴더의 **`index.html`** 전체를 붙여넣기
4. 저장 (Ctrl+S)

## 2. 배포
1. 오른쪽 위 **배포 → 새 배포 → 톱니 → 웹 앱**
2. **다음 사용자 인증 정보로 실행: 웹 앱에 액세스하는 사용자**
3. **액세스 권한이 있는 사용자: Google 계정이 있는 모든 사용자**
4. 배포 → 권한 승인 → 나온 **웹 앱 URL**이 앱 주소

## 3. 가족 초대 (인원 관리)
- 구글 드라이브에서 **☆후쿠오카 폴더 → 공유 → 가족 이메일을 편집자로 추가**
- 빼고 싶으면 공유에서 삭제하면 끝. 공유받지 않은 계정은 "접근 권한이 없어요"만 보여요.
- 시트의 **일반 액세스는 "제한됨"** 으로 바꾸기 (링크 공개 끄기)

처음 접속하는 사람은 구글이 "확인되지 않은 앱" 화면을 보여줍니다. **고급 → (안전하지 않은 페이지로) 이동 → 허용**을 한 번 누르면 됩니다.

## 4. Claude 루틴 연결 (선택)
**프로젝트 설정(톱니) → 스크립트 속성**
- `ROUTINE_FIRE_URL`, `ROUTINE_TOKEN`: claude.ai 루틴 "후쿠오카 요청 처리"의 API 트리거 URL과 토큰
- `ROUTINE_HEADERS` (선택): 루틴 화면 예시에 추가 헤더가 있으면 JSON으로

편집기에서 `testFire`를 한 번 실행해 로그에 200이 나오면 연결 성공.

## 앱 화면 업데이트
화면 코드는 `Code.gs`가 GitHub의 `apps-script/index.html`을 받아와서 보여줘요(5분 캐시). 그래서 **저장소에 푸시하면 재배포 없이 5분 안에 반영**돼요.
GitHub에서 받아오지 못하면 Apps Script에 붙여 둔 `index` 파일로 대신 열려요.

`Code.gs`(서버 코드)가 바뀐 경우에만 다시 붙여넣고 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포** 하면 같은 주소로 반영돼요.
앱 원본은 저장소의 `index.html`이고, `python3 apps-script/build.py`로 이 폴더의 `index.html`을 만듭니다.
