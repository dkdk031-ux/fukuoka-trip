# 구글 시트 붙여넣기용 템플릿

앱은 구글 시트 탭을 **헤더 이름**으로 읽습니다. 열 순서는 바뀌어도 되고, 없는 열은 무시됩니다.

## `일정` 탭 (기존 탭 교체)
`일정.tsv` 내용을 전체 복사 → 시트 `일정` 탭 A1 셀에 붙여넣기.

| 열 | 설명 |
|---|---|
| 일자 | `10/31(토)` 형식 (날짜 형식도 OK) |
| 시간 | `09:30`, `오후` 등. `HH:MM`이면 여행 당일 "지금" 표시가 정확해짐 |
| 지역 · 일정 · 세부내용 · 이동/메모 | 화면에 그대로 표시 |
| 중요 | `Y`면 빨간 점으로 강조 |
| 팁 | 노란 박스. `제목: 내용` 형식이면 제목이 굵게 |
| 주소 *(선택)* | 길찾기 목적지를 직접 지정 |
| 전화 *(선택)* | 전화 버튼 |
| 링크 *(선택)* | 링크 버튼 (http/https) |

긴린코·노가미혼칸·포르자·한큐 등 주요 장소는 이름만 적어도 길찾기·전화·공식사이트·지도 좌표가 자동으로 붙습니다.

## `일자정보` 탭 (새로 추가, 선택)
DAY 카드 상단 제목·배지·요약·성공기준. 탭이 없으면 앱에 내장된 내용이 표시됩니다.
`요약1~3`은 `라벨:값` 형식.
